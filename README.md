# Mountain Magic Homes

Marketing site for Mountain Magic Homes LLC — premium short-term mountain rentals in Virginia's Blue Ridge.

**Status:** Layout mockup with placeholder copy and images. Real content and photography to be swapped in.

## Pages

- `index.html` — Home
- `properties.html` — Properties listing
- `alpine-vista-lodge.html` — Sample property detail page
- `about.html` — About / story / team
- `contact.html` — Contact form + info

## Local preview

```bash
cd ~/mountain-magic-homes
python3 -m http.server 8000
# open http://localhost:8000
```
